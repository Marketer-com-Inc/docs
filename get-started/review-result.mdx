A polished answer can still be incomplete. Review the result against the request and the connected source before you use it to make a decision.

## Use a five-part check

### 1. Source

Confirm which system supplied each figure. Meta Ads, Google Ads, Shopify, GA4, and Triple Whale **(Beta)** can describe different parts of the customer journey. Their numbers are not interchangeable.

### 2. Time

Check the exact start and end dates, timezone, and whether either period is partial. A comparison should use equivalent windows.

### 3. Scope

Verify the workspace, provider account, campaign level, and filters. An account-level total cannot support a campaign-level conclusion unless the result also reads that campaign scope.

### 4. Calculation

Recompute the decision-driving number. For a percentage change, ask for the previous value, current value, and formula. For a ratio such as ROAS or CPA, confirm the numerator and denominator came from the intended source.

### 5. Action

Separate the analysis from the next step. A recommendation is not proof that an action ran. If the result proposes a change, confirm whether it is a draft, an item in **Awaiting action**, a paused launch, or a completed write.

<Note>
  Missing data is not zero. If a source is disconnected, syncing, or incomplete for a date, treat the affected metric as unknown until you can verify it.
</Note>

## Ask for an evidence pass

Use this follow-up when the result will inform a material decision:

```text
Audit your answer before I use it. List the source, account scope, exact dates,
timezone, and freshness for every decision-driving figure. Recalculate the main
comparison, identify missing data, and separate facts, inferences, and proposed
actions. Do not make any changes.
```

## Resolve disagreements

When the result differs from another dashboard, compare the definitions before choosing a winner:

- Platform-reported versus store- or attribution-reported conversions
- Click date versus order date
- Complete days versus a partial current day
- Workspace timezone versus provider timezone
- Selected attribution model
- Currency and any conversion rule

If the definitions align and the values still differ, save both date ranges and source labels, then use the relevant integration troubleshooting guide.
