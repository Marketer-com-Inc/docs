## A good first session

1. Create or open your workspace.
2. Connect one source that contains data you trust.
3. Ask a narrow performance question with a date range and success metric.
4. Check the sources, scope, and freshness shown with the result.
5. Save the useful context or turn the result into a reviewed next action.

<Tip>
  Start with analysis before asking Marketer to change an external system. You will learn how your connected data is represented while keeping the first task low risk.
</Tip>
