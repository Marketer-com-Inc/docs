## Adapt the examples

Replace the bracketed fields with details from your workspace. Keep the first request narrow. Add context only when it changes the answer, and state the decision the work should support.

<Note>
  A template is a starting point, not proof. Check the connected source, date window, currency, attribution context, and requested action before relying on a result.
</Note>

If your request still produces a broad answer, follow [Write effective requests](/essential-guidelines/effective-requests).
