Marketer turns a marketing outcome into work you can direct and review. Start on **Home**, give the Marketing Agent the context and boundaries it needs, then follow the request to a result or a decision.

## Orient yourself

Confirm the active workspace before you attach records or approve work. Use the main surfaces for distinct questions:

- **Home** starts a request and shows current workspace context.
- **Chats and tasks** reopens prior conversations and longer work.
- **Activity** and the **Agents** panel show progress, outputs, and sources.
- **Awaiting action** in Quick actions holds decisions that still need review.
- Product surfaces such as **Analytics**, **Campaigns**, **Creatives**, and **Workflow** show the current state of the resulting work.

## Use request → work → review

<Steps>
  <Step title="Request a clear outcome">
    Name the deliverable, evidence, scope, and authority boundary. Use `@` for an exact product, brief, campaign, or creative, and use **Add files or photos** for a one-off document.
  </Step>
  <Step title="Follow the visible work">
    A request can return a direct answer, continue as a task, ask for input, or present a proposal. Read the current state and open the task or **Agents** panel when you need its steps, sources, or outputs. Review **Dismiss**, **Edit**, and **Approve & Run** before allowing proposed work to begin.
  </Step>
  <Step title="Review the result">
    Open the actual deliverable and compare it with the request. Verify decision-driving sources, accounts, dates, attribution, currency, and freshness. Treat suggested follow-ups as new requests. If a separate connected-account change needs approval, decide it in **Awaiting action**, then confirm the result in the product surface that owns it.
  </Step>
</Steps>

<Warning>
  A completed task or approved proposal is not proof that a connected account changed. Verify the current state in the owning product surface and, when needed, the provider.
</Warning>
